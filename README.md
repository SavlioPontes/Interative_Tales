# Interactive Tales - An Adventure Through Ancient Legends 🏛️⚡

Este projeto é uma coleção de aventuras interativas baseadas em textos e narrativas, onde o usuário explora lendas antigas e mitologia. A aplicação combina leitura, narração em áudio e escolhas interativas (quizzes) para moldar o destino dos heróis ou testar o conhecimento do leitor.

O projeto foi desenvolvido como parte das atividades do projeto de extensão **Tecnologia em Educação na Casa de Cultura Britânica (CCB)**.

## 🚀 Funcionalidades

* **Antologia de Contos:** Acesso a diversas histórias independentes baseadas em mitologia (ex: "The Midas Touch", "The Abduction of Persephone").
* **Narrativa Imersiva:** Design visual temático inspirado na antiguidade clássica e uso de narração em áudio.
* **Interatividade:** O usuário participa ativamente através de escolhas e quizzes durante a leitura.
* **Menu Dinâmico:** Interface elegante com efeitos de transição e revelação suave de conteúdo.
* **Responsividade:** Layout adaptável para diferentes tamanhos de tela.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais, garantindo compatibilidade e desempenho:

* **HTML5:** Estruturação semântica das histórias e do menu principal.
* **CSS3:** Estilização avançada com uso de variáveis (`:root`), Grid Layout para a lista de histórias e fontes web ("Cinzel").
* **JavaScript (Vanilla):** Lógica para manipulação do DOM, controle de áudio e interatividade dos menus.
* **Yarn:** Gerenciador de pacotes utilizado para o controle de dependências do projeto.
